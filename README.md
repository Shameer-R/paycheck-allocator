# Paycheck Allocator

A simple Python script I made to help me budget my biweekly paychecks.

It takes my paycheck amount, sets aside money for bills and minimum debt payments, then splits what's left between spending, extra debt payments, and savings.

## How It Works

1. Uses a hardcoded paycheck amount
2. Sets aside half of my monthly bills and minimum debt payments
3. Splits the remaining money:
   - 30% for spending
   - 60% for extra debt payments
   - 10% for savings
4. Prints out how much goes into each category

Currently, all the values are hardcoded into the script.

## Tech Stack
- Python
